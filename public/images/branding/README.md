Place the official Mound Hounds image asset here:

- file name: `mound-hound.webp`
- full path: `public/images/branding/mound-hound.webp`

The app will automatically use it on:

- login page theme panel
- dashboard quick-actions mascot badge

Recommended export:

- square PNG
- at least 1024x1024

Home Screen icons are derived from this same artwork with `npm run icons:generate`.
Generated PNGs live in `public/icons`; see `docs/PWA.md` for sizes, maskable padding,
and offline-cache versioning when replacing the artwork.
